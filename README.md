# vitest-with-monitor

Integrating fn-monitor with vitest to upgrade a codebase's test suite.

> This repository is the companion example for the article
> **[Upgrade your Test Suite with fn-monitor](https://dev.to/typescript-guy/upgrade-your-test-suite-with-fn-monitor-17gn)**.
> Read the article for the full narrative — this repo holds the code.

## Run the suite

```shell
npm install
npm test
```

## What to look at

src/index.ts — the code under test
tests/index.test.ts — the upgraded suite using fn-monitor
